# HR Analytics Dashboard | Excel

## Project Overview

An interactive Excel HR analytics dashboard developed to explore workforce demographics, employee distribution, income, attrition, job roles, departments, work-life balance, and other employee-related trends.

## Project Objective

The objective of this project is to transform raw HR data into an interactive dashboard that provides clear insights into workforce patterns and supports data-driven HR decision-making.

## Key Questions

- What is the overall employee count?
- How is the workforce distributed across departments and job roles?
- What are the gender and demographic patterns within the organisation?
- What is the employee attrition level and rate?
- How does income vary across employee groups?
- What patterns exist in work-life balance and business travel?
- What workforce trends can support HR decision-making?

## Dashboard Features

The dashboard provides an overview of:

- Employee demographics
- Department distribution
- Job roles
- Income analysis
- Attrition
- Work-life balance
- Business travel
- Employee trends

## Key Insights

The analysis provides a visual overview of workforce characteristics and highlights patterns in employee demographics, departmental distribution, income, attrition, and work-life balance.

These insights can help HR teams identify workforce patterns and support evidence-based decisions around employee retention and workforce management.
